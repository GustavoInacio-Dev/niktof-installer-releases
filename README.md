# Niktof Installer - downloads

Aqui ficam só as **versões publicadas** do Niktof Installer (instalador do PACK PMSP + IA para GTA V Legacy).

- Cada [Release](https://github.com/GustavoInacio-Dev/niktof-installer-releases/releases) tem o `NiktofInstaller.exe` e o `versao.json`.
- O Niktof Installer lê o `versao.json` do último Release pra saber se tem versão nova, baixa o `.exe`, confere o SHA-256 e se atualiza sozinho.
- Este repositório **não tem código-fonte, nem chaves de API, nem os arquivos do pack**.
